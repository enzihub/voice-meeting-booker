Voice Meeting Booker

An AI voice agent calls your prospect, talks it through, and books the meeting. You watch the call and the transcript live, then see the slot it agreed.

Run it locally → View the code
Demo

One call, start to finish

Recorded from the real app running locally. VAPI is replaced by a small fake that plays back a scripted call, so the people and numbers are invented.

How it works

From a phone number to a booked meeting

01 · browser

Enter a number

Type a US number and, if you like, the prospect's name and notes, the agent's name, voice and caller line.

POST /api/create-call
02 · VAPI

The agent calls

VAPI dials out with your assistant. Your notes and the agent's name go in as call variables.

POST https://api.vapi.ai/call
03 · live

Watch the transcript

The page polls the call: ringing, live, then each line of the conversation as it happens.

GET /api/call-status/:id
04 · OpenAI

Meeting booked

When the call ends, the agreed slot comes from VAPI's structured data or is read from the transcript by OpenAI.

POST /api/webhooks/vapi-call
Features

What is in the box

Live call view

See the call as it happens

A call card shows who is calling whom, a status badge (queued, ringing, live, ended), a timer and a waveform. Transcript lines appear as the two sides speak.

Outcome

The slot it agreed, not just a recording

When the call ends, the page shows the meeting as a calendar card. The webhook gets the same slot, ready for your calendar integration.

Settings

Brief the agent before it dials

Give the prospect's name and notes, rename the agent, choose a voice persona and a caller line. Voices and lines come from your environment, so nothing account-specific lives in the code.

Three agents, one codebase

Meeting booker, SDR and payment reminder

Each mode uses its own VAPI assistant and its own copy. The call flow, settings and live view are shared.

Quick start

Run it in two minutes

The demo mode needs no accounts. It starts a tiny fake of the VAPI API and points the app at it.

# clone and install
git clone https://github.com/enzihub/voice-meeting-booker
cd voice-meeting-booker
npm install

# no keys: fake VAPI + the app on http://127.0.0.1:3000
npm run demo

# real calls: fill in your VAPI and OpenAI keys
cp .env.example .env.local
npm run dev
VariableWhat it is for
VAPI_API_KEYYour VAPI private key. Needed for real calls.
VAPI_ASSISTANT_IDFallback assistant. Per mode: VAPI_ASSISTANT_ID_MEETING_BOOKER, _SDR, _REMINDER.
VAPI_PHONE_NUMBER_IDThe VAPI phone number the agent calls from.
VAPI_PHONE_NUMBERS, VAPI_VOICESOptional JSON lists for the caller lines and voices offered in Settings.
VAPI_WEBHOOK_SECRETOptional. Checked against the x-vapi-secret header on the webhook.
OPENAI_API_KEYReads the agreed slot out of the transcript when VAPI has no structured data.
